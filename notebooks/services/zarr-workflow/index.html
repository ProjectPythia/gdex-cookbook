Overview¶

This notebook demonstrates a complete analysis workflow using GDEX ARCO (Zarr-format) data, from discovery through analysis and visualization.

  1. Verify ARCO availability and explore variables

  2. Open the Zarr store lazily with xarray + Dask

  3. Select a region and time period

  4. Compute a diagnostic and visualize the result
