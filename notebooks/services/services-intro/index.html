GDEX offers several ways to discover, access, and download data, each suited to different workflows and access levels. The pages in this section introduce each service and link to deeper, hands-on notebooks.

ServiceDescriptionAccess Type
🌐 TDSAccess datasets remotely via OPeNDAP, NCSS, WMS, and other THREDDS protocols without downloading files.Streaming
⚡ ZarrOpen Analysis-Ready Cloud-Optimized (ARCO) datasets in Zarr or “Virtualized” Zarr format for fast, chunk-aware remote access.Streaming
🔌 APIUse the GDEX REST API to discover datasets, retrieve metadata, and request subsets programmatically.Streaming / Downloading
📥 DownloadDownload entire files to your local machine for offline access.Downloading
🗂️ POSIXRead GDEX datasets directly from the NCAR HPC filesystem without an explicit transfer step.Streaming
🚀 GlobusTransfer large GDEX datasets to your institution or HPC system at high speed with Globus.Downloading
